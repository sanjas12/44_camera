# Снимки с камеры ноутбука

Python-программа сохраняет снимки с локальной веб-камеры в формате PNG без потерь. По умолчанию интервал — **5 секунд**. Камера работает, пока запущена программа; остановка — **Ctrl+C**. Снимки сохраняются локально, программа никуда их не отправляет.

## Установка через uv

Откройте PowerShell в папке проекта и выполните:

```powershell
uv sync

```

## Запуск

Снимок каждые 5 секунд:

```powershell
uv run camera.py
```

Снимок каждые 10 секунд:

```powershell
uv run camera.py --interval 10
```

Можно указать дробный интервал, например `--interval 0.5`. Интервал должен быть больше нуля. Чтобы изменить его, остановите программу и запустите снова с нужным значением.

Выбор камеры и папки сохранения:

```powershell
uv run camera.py --interval 5 --camera 0 --output "D:\CameraPhotos"
```

По умолчанию используется камера с индексом `0`, а снимки сохраняются в папке `snapshots` рядом со скриптом. Если подключено несколько камер, попробуйте `--camera 1`. Имена файлов содержат дату, время и микросекунды.

Первый снимок сохраняется сразу после получения кадра; следующие — с выбранным интервалом. Фактическая частота ограничена скоростью камеры и записи на диск. Между снимками программа читает кадры, чтобы получать актуальное изображение.

На Windows, Linux и macOS используются одинаковые команды uv. Команда `uv sync` установит Python 3.12 при необходимости, создаст `.venv` и установит зависимости из `uv.lock`. Активировать окружение вручную не нужно. Зависимости проекта описаны в `pyproject.toml`; `uv.lock` фиксирует их версии и должен храниться вместе с кодом.

## Если камера не открывается

Закройте приложения, которые могут занимать камеру, проверьте её подключение и разрешение на использование камеры настольными приложениями в настройках Windows. При ошибке чтения кадра или записи файла программа сообщает причину и завершает работу, освобождая камеру.

Автоматическое удаление снимков не предусмотрено — следите за свободным местом на диске.


### Размещение Python и кеша на диске D

На этом компьютере на диске C недостаточно места, поэтому Python и кеш установлены внутри проекта на диске D. В каждом новом сеансе PowerShell перед командами uv выполните:

```powershell
$env:UV_CACHE_DIR = "D:\My_work\Python\44_camera\.uv-cache"
$env:UV_PYTHON_INSTALL_DIR = "D:\My_work\Python\44_camera\.uv-python"
```

Эти служебные папки исключены из Git.

## Автоматическое качество

При запуске программа проверяет распространённые разрешения вплоть до 8K и выбирает наибольшее по числу пикселей, подтверждённое реальными кадрами. Выбранный размер выводится в консоль. Проверка занимает дополнительное время при запуске; первый снимок сохраняется после неё. Если более высокие режимы недоступны, используется рабочий режим камеры.

PNG сохраняет полученный кадр без дополнительного сжатия с потерями. Файлы могут занимать значительно больше места, чем JPEG. Размер кадра ограничен камерой и драйвером. Перебор типовых режимов не гарантирует обнаружение редкого нестандартного разрешения или отдельного аппаратного режима фотосъёмки; качество оптики, освещение и обработка внутри камеры также влияют на результат.

## Сборка приложения без установленного Python

Сборка выполняется на целевой ОС и архитектуре. В PowerShell из папки проекта:

```powershell
uv sync --locked --group build
.\.venv\Scripts\python.exe build.py build_exe
```

На Linux/macOS используйте `.venv/bin/python build.py build_exe`.
Готовое консольное приложение находится в `build/laptop-camera-0.1.0-<os>_<arch>-py<version>/`.
Переносите **весь этот каталог**, включая `lib` и библиотеки, а не только exe.
В Windows запустите `laptop-camera.exe` из PowerShell; параметры `--interval`,
`--camera` и `--output` остаются прежними. По умолчанию `snapshots` создаётся рядом
с exe, поэтому каталог приложения должен быть доступен для записи.
Консоль нужна для сообщений и остановки через Ctrl+C.

Для Git Bash, Linux или macOS доступны команды:

```bash
bash scripts/build.sh --prepare         # установить зависимости и собрать
bash scripts/build.sh                   # собрать из готовой .venv без скачивания
bash scripts/build.sh --prepare-offline # подготовить зависимости из кеша uv и собрать
```

Скрипты работают и при запуске из другого каталога. Старые сборки автоматически
не удаляются. Для полной пересборки удалите нужный каталог результата вручную.
Для пересоздания `.venv` с зависимостями приложения и сборки используйте
`bash scripts/recreate_env.sh` (или добавьте `--offline` для кеша uv).
Эта команда очищает текущее виртуальное окружение; в офлайн-режиме необходимые
пакеты и Python должны быть доступны локально. Группа `build` хранится в
`pyproject.toml` и фиксируется в `uv.lock`; для обычного запуска достаточно `uv sync`.

## Скачивание библиотек для компьютера без интернета

Проект использует Python 3.13 (см. `.python-version`). На целевом компьютере нужен Python той же minor-версии, Windows x64. Установщик Python переносится отдельно.

В папке проекта выполните (одинаково в PowerShell и Git Bash):

```text
uv run --with pip python scripts/download_packages.py --destination F:/temp/python_Library
```

Скрипт автоматически согласует версию Python и ABI, экспортирует зафиксированные зависимости приложения и группы `build` из `uv.lock` в каталог загрузки и скачивает готовые wheels вместе с зависимостями. Для загрузки только библиотек камеры добавьте `--runtime-only`. При ошибке скрипт завершается с ненулевым кодом; каталог может содержать частичную загрузку, повторный запуск продолжит её.

Перенесите каталог на офлайн-компьютер. Установка без интернета:

```text
py -3.13 -m venv .venv
.venv/Scripts/python.exe -m pip install --no-index --find-links F:/temp/python_Library -r F:/temp/python_Library/requirements.txt
.venv/Scripts/python.exe camera.py
```

При ручном скачивании для Python 3.13 используйте `--python-version 3.13 --abi cp313`. Сочетание `--python-version 3.12 --abi cp313` неверно. Сообщения `Ignoring` для macOS/Linux нормальны на Windows. Если после исправления параметров пакет всё ещё недоступен, проверьте наличие wheel указанной версии в используемом индексе. Документация: https://pip.pypa.io/en/stable/cli/pip_download/
